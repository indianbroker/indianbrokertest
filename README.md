# Indian Broker Test

An independent, publication-style comparison website for Indian stock brokers, built with **Astro.js (SSG)**. Every page is pre-rendered static HTML with inlined CSS and **zero client-side JavaScript**, targeting Lighthouse 100 in Performance, Accessibility, Best Practices and SEO.

## Quick start

```bash
npm install
npm run build     # static output in dist/
npm run preview   # serve dist/ locally
npm run dev       # dev server
```

Requires Node.js 18.17+ (Node 20+ recommended).

## Editorial independence (non-negotiable)

- The site is affiliated with **no broker**. Arrow, Zerodha, Upstox, Groww and every other broker are rendered by the same components with the same styling.
- **Rankings are computed, never hardcoded.** `rankBySpeed`, `rankByFee` and `rankByApi` sort only brokers that have a published figure; everyone else falls to an unranked "Not Disclosed" section.
- **No number is ever invented.** If a metric isn't published on the broker's official site or a top-ranked published comparison, the field is `null` in `brokers.js` and renders as **Not Disclosed**.
- Execution-speed figures come from one cited published comparison which is explicitly badged **self-reported**. The brokers which publishes no verifiable speed figure, shows Not Disclosed.
- Every article ends with a **Sources** section; the speed table carries an inline citation and a caveat note.

## Updating data

1. Edit `src/data/brokers.js` only. Each broker is one object; set a field to `null` if it isn't publicly published (it will render as "Not Disclosed").
2. Update `DATA_COMPILED` to the date you verified the figures.
3. If you add a new source, register it in `SOURCES` and reference its key via `sourceId`.
4. Rebuild. Rankings, tables, profile pages, schema and the sitemap regenerate automatically. Adding a broker object automatically creates its profile page via `src/pages/brokers/[slug].astro`.

## ⚠ Verify before deploying

Brokerage rates, AMC, API pricing and speed figures in `brokers.js` were compiled from official pricing pages and one published comparison as of the `DATA_COMPILED` date, but brokers change pricing frequently. **Re-verify every figure against each broker's official pricing page (URLs are stored per broker in `pricingUrl`) before publishing**, and update `DATA_COMPILED` accordingly.

## SEO / performance notes

- Canonicals, Open Graph (en_IN), Twitter Cards, `max-snippet:-1` robots meta, Breadcrumb/FAQ/Article/ItemList/CollectionPage/Organization/WebSite JSON-LD on the relevant pages.
- FAQ schema text is always identical to the visible on-page FAQ text (rendered from the same array).
- `trailingSlash: 'always'` with matching internal links; sitemap generated by `@astrojs/sitemap`.
- System font stack (no webfonts), all CSS inlined, no images in the critical path, no layout shift, no render-blocking resources.
- Set your production domain in `astro.config.mjs` (`site`) before deploying; sitemap and canonical URLs derive from it.
